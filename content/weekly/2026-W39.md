### The Intermediate track is complete (D4, #2003)

Paulo Bressan's lectures **10–13** merged into the Developer Portal's
`new-onboarding` branch on Thursday: **77 files, +6,152 / −92**. That closes
the Intermediate track. A reader now goes from a first validator to a consumer

The four lectures merged as reviewed: **handling time** (a vesting deadline
enforced through the validity window), **multi validators** (a gift card with a
`mint` and a `spend` handler under a one-shot policy), **modifying state** (an

### Event-triggered assets went from spec to code (D5)

Nine commits from Sofia Bobbiesi on `28-explore-event-triggered-assets`
(**+2,023 / −1,018 across 19 files**). On Monday the tokenized-bond spec
described last week replaced the original 138-line exploration document. The
rest of the week implemented it, adding three new on-chain modules that each
take one section of the spec:

- **`schedule.ak`, the baked-value arithmetic.** The four-step schedule is
  compiled in as fixed-point constants, so the recorded value is a pure
  `lookup(schedule, now)` with no on-chain compounding. The graduation payout is
  **per owner**: `floor(Q_owner × v4 / scale)`, summed. Rounding dust is never
  minted, so nobody gains by batching graduations.
- **`transformation.ak`, the time gate.** A withdraw-0 script attached as the
  CIP-68 reference token's stake credential. It accepts the in-place datum
  update only for `d1 ≤ now < d4`, with no signatures. Anyone may submit, and a
  late submission simply lands on the current step. After `d4` it rejects every
  update, and the value stops.
- **`native_mint.ak`, the graduated asset's policy.** A new native policy that
  is signer-agnostic but **"no burn, no mint"**. It approves a mint only as the
  exact scaled mirror of a governed burn of the same name under the bond's
  CIP-113 policy, and it computes the amount with the same function the burn
  side validates, so the two scripts cannot disagree.

`issuance`, `transfer`, `third_party` and the validator were refactored around
these modules, and the MeshJS driver was reworked to match.
